# Paletas

As 18 paletas embutidas ficam no código. As paletas personalizadas criadas no editor são gravadas em `palettes/custom.toml`.

- Selecione uma paleta no combo **Paleta**.
- Clique em **Personalizar paleta** para editar as cores.
- **Salvar na biblioteca** grava ou atualiza a paleta pelo nome.
- **Excluir da biblioteca** remove a entrada; a paleta que já está no preset continua local.
- **Aplicar às 4 barras** copia a paleta global para todas as barras.

O arquivo é TOML e pode ser editado à mão. Paletas com nome de uma paleta embutida são ignoradas ao carregar.
