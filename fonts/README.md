# Fontes

Coloque arquivos `.ttf` ou `.otf` nesta pasta. Eles aparecem no seletor **Fonte** da seção Texto, junto com a Inter embutida e as fontes do sistema. Se adicionar com o app aberto, use o botão **Atualizar** ao lado do seletor.

O app também varre:

- `~/Library/Fonts`
- `/Library/Fonts`
- `/System/Library/Fonts/Supplemental`

Arquivos `.ttc` não entram na lista.
